# Changelog

## 0.5.0 — 2026-10-17

First public preview.

- Monitor with file, camera and RTSP source controls.
- Local posture, smoke and flame detection on CPU.
- Causal episode memory, delayed assessment and guarded recovery handling.
- Bounded capture, inference, evidence storage and cloud scheduling.
- Versioned HTTP API, synchronous/asynchronous Python SDK and integration examples.
- Monochrome identity and installable release assets with SHA-256 checksums.

See [known limitations](docs/limitations.md) before deployment.
